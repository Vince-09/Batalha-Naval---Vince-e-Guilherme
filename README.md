# Batalha Naval – EP2 DesSoft

# Como jogar
1. Rode o jogo no terminal:
   - python programa.py
2. Posicione seus navios no tabuleiro 10x10, informando linha, coluna e orientação:
   - 1 porta-aviões (4 casas)
   - 2 navios-tanque (3 casas)
   - 3 contratorpedeiros (2 casas)
   - 4 submarinos (1 casa)
3. Em cada rodada, escolha uma linha e uma coluna para atacar o oponente.
   - X = acertou um navio
   - '-' = acertou a água
4. Depois de cada jogada sua, o oponente ataca uma posição sorteada.
5. Vence quem afundar todos os navios do adversário primeiro.

# Arquivos
- funcoes.py: funções do jogo (posicionar navios, validar posições, fazer jogadas, contar navios afundados)
- programa.py: o jogo em si (entrada de dados, tabuleiros na tela e rodadas)
